# 👥 User Personas

Understanding our users helps guide every design and engineering decision.

---

## 👤 Persona 1: DevOps Dan

- **Age:** 29
- **Role:** DevOps Engineer at a 5-person startup
- **Tech Stack:** AWS, Linux, Docker, Node.js
- **Goals:**

  - Wants a central dashboard for chat, note-taking, server status, and command execution
  - Needs privacy-first tools that can be self-hosted
  - Avoids Slack/Notion due to cost and vendor lock-in

- **Frustrations:**
  - Switching between 4–5 apps for routine ops
  - Sharing SSH credentials with team members
  - Monitoring multiple servers manually

---

## 👩 Persona 2: Freelancer Freya

- **Age:** 24
- **Role:** Full-stack developer working with multiple clients
- **Tech Stack:** React, Node.js, Firebase, GitHub
- **Goals:**

  - Easily share project notes, files, and chat with clients
  - Quickly check server health without logging into each one
  - Access remote server functions (like restarting a process) via browser

- **Frustrations:**
  - Non-technical clients don’t want to use Slack/Notion
  - No easy way to run one-off shell commands from phone
  - Existing tools are bloated or have too many dependencies
